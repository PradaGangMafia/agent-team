# Review the reference code

`ref/master.py` is a small inventory reporting script. Review it the way a
senior engineer would before a refactor.

## Requirements

1. Read every line of `ref/master.py`. Do not modify it.
2. Write `work/master_review.md` containing:
   - a one-paragraph summary of what the script does and its intended input
     format;
   - a table of every defect and code smell you can find, with the line or
     function name, severity (`blocker` / `major` / `minor`), and why it
     matters. Include at least: crash-level bugs, unsafe defaults, exception
     handling problems, resource handling, I/O assumptions, and formatting /
     typing issues;
   - a list of concrete, prioritised recommendations for the refactor;
   - anything you could not verify without a real `data/stock.csv` file.
3. Optionally demonstrate a bug you found by running a short Python snippet via
   `run_python` and quote the traceback in the review. Do not create files
   outside `work/`.
4. Write the detailed log to `logs/p01.log`.

## Deliverables

- `work/master_review.md`
- `logs/p01.log`
