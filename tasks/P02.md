# Refactor and test

Continue from `work/master_review.md` (task P01). Turn `ref/master.py` into a
correct, testable module.

## Requirements

1. Read `ref/master.py` and `work/master_review.md` before writing code.
2. Create `work/master_refactored.py`:
   - Python 3 standard library only;
   - type hints and docstrings;
   - fix every `blocker` and `major` finding from the review (crash on
     formatting, mutable default argument, bare `except`, leaked file handle,
     missing encoding, silent bad-number handling, no CLI for the data path);
   - accept a CSV path as a command-line argument, defaulting to
     `data/stock.csv`;
   - fail with a clear message and non-zero exit code when the file is missing;
   - keep the same overall behaviour: totals per item, sorted output, and a
     low-stock list.
3. Create `work/test_master_refactored.py` using `unittest`, covering at least:
   totals across repeated items, malformed numbers, empty input, the formatting
   fix, and the low-stock threshold.
4. Run the tests with `run_python` or `run_shell` and record the real output
   (command + exit code) in the log. They must pass.
5. Keep a short `work/README_p02.md` note describing how to run the module and
   the tests.
6. Write the detailed log to `logs/p02.log`.

## Deliverables

- `work/master_refactored.py`
- `work/test_master_refactored.py`
- `work/README_p02.md`
- `logs/p02.log`
