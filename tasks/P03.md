# Image batch from a master image

`ref/master_image.png` is the approved master artwork. Create a batch of
variations that stay unmistakably on-model.

> This task needs a working image endpoint (`IMAGE_*` in `.env`). If image
> generation is unavailable, call `finish_task` with `status: "blocked"` and
> state exactly which setting or endpoint failed — do not substitute
> placeholder files.

## Requirements

1. Inspect `ref/master_image.png` with `read_image` and write down the
   invariants you must preserve (subject, palette, style, framing).
2. Produce **five** distinct variations in `work/images/` named
   `variant_01.png` … `variant_05.png`. Each must be a real generated image.
3. Vary one or two dimensions per variant, for example: pose, camera angle,
   colourway, time of day, expression. Keep the character/style identical and
   restate the invariants in every prompt.
4. Prefer the master image as a reference for each generation
   (`references: ["ref/master_image.png"]`) so the endpoint performs
   image-to-image rather than text-to-image.
5. Inspect your outputs with `read_image`. Regenerate any variant that drifts
   off-model, is cropped, or contains artefacts.
6. Write `work/images/prompt_sheet.md` listing, per variant, the prompt used
   and what changed.
7. Write the detailed log to `logs/p03.log`, including the backend used
   (`images` or `chat`), the sizes, and which variants needed a retry.

## Deliverables

- `work/images/variant_01.png` … `work/images/variant_05.png`
- `work/images/prompt_sheet.md`
- `logs/p03.log`
